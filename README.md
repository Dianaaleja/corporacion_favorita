### Corporación Favorita Time Series Forecasting
📌 Project Overview
This project focuses on time series forecasting for Corporación Favorita, a major retailer, using advanced machine learning techniques. The goal is to predict future sales trends to aid in inventory management, demand planning, and business decision-making.

Additionally, we have built an interactive Streamlit application to visualize forecasts and enable user-friendly model interaction.

🚀 Features
Exploratory Data Analysis (EDA): Identify seasonality, trends, and anomalies in sales data.
Data Preprocessing: Handle missing values, outliers, and feature engineering for improved forecasting.
Time Series Models: Implement ARIMA, Prophet, LSTM, XG-Boost and other forecasting methods.
Model Evaluation: Compare performance using RMSE, MAE, and MAPE metrics.
Streamlit Web App: Interactive interface for real-time forecasting visualization.

🏗️ Streamlit Application

The Streamlit app provides an easy-to-use interface where users can:
✅ Upload custom sales data for prediction.
✅ Select forecasting models dynamically.
✅ Visualize historical sales trends and future predictions.
✅ Download forecast results for further analysis.
